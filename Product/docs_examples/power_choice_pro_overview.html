Product definition

A practical workspace for decisions that deserve more than a spreadsheet.

Power Choice Pro creates a shared structure around the questions, alternatives, factors, and people involved—without exposing users to the statistical machinery underneath.

Structure the decision

Define the project, capture viable alternatives, and use Overall Assessment or a reusable set of factors.

Collect meaningful input

Invite participants through email or copy-and-paste links, with carefully limited access to the selection process.

Explain the result

See recommendations, rankings, confidence, stability, factor performance, participation, and areas of disagreement.

Common use cases

Choose a software platform or implementation partner
Prioritize a product roadmap or strategic portfolio
Compare vendors, locations, candidates, or proposals

Designed for clarity

Plain-language terminology: Projects, Alternatives, Factors
Preliminary results are visibly distinguished from final results
Data and interpretation are presented separately

Built for real participation

Email, invitation text, and private participation links
Explicit access levels and revocable invitations
Focused, mobile-friendly participant experience
Project modes

One product, two clear result experiences.

CHOICE PROJECT

Select one preferred alternative

Best when the outcome needs a recommended choice rather than a long ranked list.

  • Recommended alternative and confidence
  • Separation from the next-best option
  • Key contributing factors
  • Agreement and disagreement
PRIORITIZATION PROJECT

Put alternatives in a useful order

Best when several initiatives or opportunities may proceed, but sequence and emphasis matter.

  • Ranked alternatives and relative strength
  • Tiers or natural groupings
  • Ranking stability and movement
  • Factor-level performance
Guided workflow

From a blank project to a result people can understand.

A setup wizard guides new users through the minimum required steps, while experienced users can move directly among the same project pages.

6

Review results

Recommendation, ranking, confidence, factors, and participation.

Collaboration

Invite participation without exposing project administration.

The invitation experience is deliberately narrower than the full application. Participants see the project context, complete their requested selections, and receive only the result access granted by the owner.

Flexible invitation delivery

Send by email, copy a private link, or copy a ready-to-paste invitation message.

Explicit access levels

Voting only, individual summary, limited aggregate summary, or a full report after closure.

Manage the lifecycle

Track sent, opened, in-progress, completed, expired, and revoked invitations.

Results experience

The result page is the product’s moment of truth.

It must be attractive enough for a presentation and transparent enough to support a serious conversation.

Clear outcome

Recommended choice or ranked priorities, with confidence and rank stability.

Multiple perspectives

Equal-weight and factor-weighted views, plus factor importance and alternative performance.

Participation context

Completion, agreement, disagreement, comments, and result changes over time.

Ready to communicate

Print, export, copy summary, presentation view, and controlled sharing.

Production direction

Designed to translate cleanly into Nuxt 3 and TypeScript.

Representative Project interface
interface Project {
  id: string
  title: string
  description?: string
  mode: 'choice' | 'prioritization'
  visibility: 'personal' | 'shared'
  status: 'draft' | 'collecting' | 'closed' | 'archived'
  alternatives: Alternative[]
  factors: Factor[]
  participantAccess: ResultAccess
  deadline?: string
  createdAt: string
  updatedAt: string
}
Representative Invitation interface
interface Invitation {
  id: string
  projectId: string
  email?: string
  token: string
  status: 'sent' | 'opened' | 'in_progress' | 'completed' | 'expired' | 'revoked'
  resultAccess: ResultAccess
  expiresAt?: string
  lastActivityAt?: string
}
Representative ResultSummary interface
interface ResultSummary {
  projectId: string
  state: 'preliminary' | 'final'
  recommendedAlternativeId?: string
  ranking: RankedAlternative[]
  confidence: number
  stability: number
  factorResults: FactorResult[]
  participation: ParticipationSummary
  generatedAt: string
}
