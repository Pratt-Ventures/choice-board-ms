### 3) Options & trade-offs

- **Hide vs. remove top-half mode**: hard-delete the option/button everywhere is cleaner but breaks display for saved projects; **recommended**: hide for new selection + preserve value with legacy indicator (matches expanded note that `find_top_half` remains internally valid).
- **Deduplicate mode labels via shared helper vs. inline ternaries**: helper adds a tiny abstraction but prevents future drift across ~7 call sites; recommended given the rename touches many files.
- **Per-user detection source**: reuse summary's `my_observation_count` (zero backend work, already partial-inclusive) vs. new endpoint/share-session-aware check; recommended reuse — share participants use the share flow, not the customer overview, so logged-in identity suffices.
- **Interstitial reorder location**: change inside `CompareQuestionHeader` (one component, both probe and share flows consistent) vs. reordering in each page; recommended component-level change scoped to `variant === 'intro'`.
